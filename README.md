# 👁️ AI Vision Classifier

A web-based Computer Vision application that uses a pre-trained Vision Transformer (ViT) to identify and classify objects within uploaded images.

## Features
* **Image Classification:** Leverages Google's ViT model for high-accuracy object recognition.
* **Interactive UI:** Built entirely in Python using Streamlit for seamless image uploading and real-time inference.
* **Cloud Deployed:** Hosted on Streamlit Community Cloud for continuous availability and immediate access.

## Tech Stack
* Python
* Hugging Face (`transformers`)
* PyTorch
* Pillow (PIL)
* Streamlit
